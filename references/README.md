# WeatherGPT Literature & Research References

This folder contains academic literature, reference papers, and scholarly works that serve as conceptual, architectural, and algorithmic foundations for **WeatherGPT**.

For detailed bibliographies, BibTeX records, and copyright statements, please see the root [**REFERENCES.md**](../../REFERENCES.md).

---

### Papers in this Directory

1. **[A Contemporary Review on Chatbots, AI-Powered Virtual Conversational Agents, ChatGPT](papers/A_Contemporary_Review_on_Chatbots_AI_Powered_Conversational_Agents_ChatGPT.pdf)**
   * *Authors:* Avyay Casheekar, Archit Lahiri, Kanishk Rath, Kaushik Sanjay Prabhakar, Kathiravan Srinivasan (VIT, 2024)
   * *Published in:* *Computer Science Review* (Elsevier), Vol. 52, 100632. [DOI: 10.1016/j.cosrev.2024.100632](https://doi.org/10.1016/j.cosrev.2024.100632)
   * *Focus:* Conversational agent architectures, UI/UX evaluation frameworks, and LLM safety paradigms.

2. **[Kissan-Dost: Bridging the Last Mile in Smallholder Precision Agriculture with Conversational IoT](papers/Kissan_Dost_Conversational_IoT_Precision_Agriculture.pdf)**
   * *Authors:* Muhammad Saad Ali, Daanish U. Khan, Laiba Intizar Ahmad, Umer Irfan, Maryam Mustafa, Naveed Anwar Bhatti, Muhammad Hamad Alizai (LUMS, 2026)
   * *Published on:* arXiv (arXiv:2602.08593 [cs.HC]). [arXiv:2602.08593](https://arxiv.org/abs/2602.08593)
   * *Focus:* Sensor-grounded telemetry retrieval-augmented generation (RAG) and low-latency multilingual voice guidance.
